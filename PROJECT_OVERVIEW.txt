SVN2GitHub Project Overview

The supported application consists of:
- A .NET 8 WPF desktop client in wpf/SVN2GitHub.
- An ASP.NET Core API and migration workflow in backend/SVN2GitHub.Api.
- A local SQLite store at data/local_migrations.sqlite3.

The WPF app communicates with the API at http://127.0.0.1:5000. The API
coordinates SVN analysis, author mapping, git-svn import, optional history
cleaning, GitHub setup, push, and ref verification.

Build both projects with:
  dotnet build wpf\SVN2GitHub.sln --configuration Debug

Launch the desktop application with:
  .\start.ps1

External migration requirements include Git with git-svn, the Subversion
client, and GitHub CLI. History cleaning optionally uses git-filter-repo.
See README.md and DOCUMENTATION_INDEX.md for current instructions and
limitations. The former Python implementation has been retired.
