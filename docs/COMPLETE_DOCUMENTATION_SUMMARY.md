# Documentation Status

This index replaces the historical documentation generated for the former
Python backend. Current architecture and operating instructions are maintained
in the root [documentation index](../DOCUMENTATION_INDEX.md).

The current implementation uses an ASP.NET Core API and WPF client. For
installation, migration prerequisites, data handling, and known limitations,
see the [README](../README.md) and [setup guide](../SETUP.md).

Guides now cover the interactive live dashboard, fixed wizard footer,
right-side AI history and clear-key behavior, and manual checkpoint Resume.
See [Portable package](../PORTABLE_PACKAGE.md) for bundled tools, per-user
storage, publishing, and stale-ZIP status. Validation evidence is recorded in
[Test results](../TEST_RESULTS.md), not inferred from historical filenames.
The [Copilot guide](AI_COPILOT_GUIDE.md) covers guided tasks and local refresh,
with readiness and diagnostic support reports that do not claim enterprise
audit or migration acceptance.
