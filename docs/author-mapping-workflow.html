Author Mapping Workflow

How SVN usernames are mapped to Git author identities in your WPF application

1
User Opens Author Mapping

From the New Migration form, click "Configure" in the Author Mapping section.

The system opens the Author Mapping Window where you can review and edit all SVN to Git author mappings.

2
Extract Authors from SVN

Click "Load From SVN" button to automatically extract all unique authors from your repository's history.

svn log --quiet --limit 5000 https://your-svn-repo r1 | jdoe | 2010-01-15 10:30:00 ... r2 | asmith | 2010-01-16 14:22:00 ... r3 | bwilson | 2010-01-17 09:15:00 ... ✓ Extracted 3 unique authors

Note: This may take 2-5 minutes for repositories with 15 years of history. The agent extracts from the last 5000 commits for performance.

3
Auto-Generate Git Identities

The system automatically converts SVN usernames to Git format using intelligent heuristics:

SVN Username Generated Git Name Generated Git Email
jdoe Jdoe jdoe@example.com
john.doe John Doe john.doe@example.com
alice.m.smith Alice M Smith alice.m.smith@example.com

Algorithm: Split by dots, capitalize each part. Fallback to simple capitalization.

4
Review & Edit in UI

The WPF UI displays all authors in an editable grid:

5
Save to Database

Click "Save & Close" to persist all mappings to SQLite database.

POST /api/authors/{migration_id}/bulk { "authors": [ { "svn_username": "jdoe", "git_name": "John Doe", "git_email": "john.doe@company.com", "verified": true }, ... ] } ✓ Saved 3 author mappings
6
Generate authors.txt

During migration, the system exports authors to authors.txt file in git-svn format:

jdoe = John Doe <john.doe@company.com> asmith = Alice Smith <alice.smith@company.com> bwilson = Bob Wilson <bob.wilson@company.com>

This file is used by git-svn clone --authors-file=authors.txt to properly attribute commits.

7
Migration Runs

The migration agent uses the authors file to convert SVN commits to Git commits with proper attribution:

git svn clone https://svn-repo \ --authors-file=authors.txt \ --stdlayout \ --prefix=svn/ Converting SVN commits to Git... r1 = abc123 (jdoe → John Doe <john.doe@company.com>) r2 = def456 (asmith → Alice Smith <alice.smith@company.com>) ✓ Migration complete!

Key Features

🤖
Automatic Extraction
Scans entire SVN history (up to 5000 commits) to extract all unique authors automatically.
✨
Smart Generation
Intelligently converts usernames like "john.doe" to "John Doe" with proper capitalization.
✏️
Interactive Editing
Full-featured grid with search, inline editing, verification checkboxes, and manual additions.
💾
Persistent Storage
All mappings saved to database and available across sessions and migrations.
📤
Export Capability
Export to standard authors.txt format for use with external git-svn tools.
🔄
Real-time Updates
Edit authors during migration; changes apply immediately without restarting.

API Endpoints

GET /api/authors/{migration_id}
Retrieve all author mappings for a migration
POST /api/authors/{migration_id}/extract
Extract authors from SVN repository and generate default mappings
POST /api/authors/{migration_id}/bulk
Bulk update all author mappings at once
GET /api/authors/{migration_id}/export
Export authors in git-svn compatible authors.txt format
